# Claude Instructions

Read `AGENTS.md` before working in this repository.

If `AGENTS.local.md` exists, read it as private local instructions.
If `CLAUDE.local.md` or `.claude/*.local.md` exists, treat it as private local context.
Never commit, quote, summarize into public files, or disclose local instruction files.

For non-trivial repo work, follow `.agents/commands/feature-pr.md`.
For verification, follow `.agents/commands/verify.md`.
For review, follow `.agents/commands/review.md`.
For PR creation, follow `.agents/commands/open-pr.md`.
For PR follow-up, CI failures, and CodeRabbit/human review comments, follow `.agents/commands/pr-follow-up.md`.
For PR review comments only, follow `.agents/commands/respond-to-pr-comments.md`.
Before PR/commit, use `.agents/commands/pre-pr.md`.
Project-specific risk rules live in `.agents/commands/llm-tracker.md`.
